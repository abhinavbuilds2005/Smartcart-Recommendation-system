# 🛒 SmartCart — Customer Segmentation

A machine learning project that segments customers based on their 
purchasing behavior and demographics using unsupervised learning techniques.

## 🔍 What it does
- Cleans and preprocesses real customer marketing data
- Engineers features like Age, Total Spending, Customer Tenure
- Removes outliers and encodes categorical variables
- Reduces dimensions using PCA (3 components)
- Finds optimal clusters using Elbow Method & Silhouette Score
- Segments customers using KMeans & Agglomerative Clustering
- Visualizes clusters in 3D and summarizes each segment

## 🛠️ Tech Stack
- Python, Pandas, Scikit-learn
- Matplotlib, Seaborn
- Streamlit (deployed)

## 📊 Dataset
Customer personality analysis dataset with 2200+ records and 
29 features including income, spending habits, and demographics.
